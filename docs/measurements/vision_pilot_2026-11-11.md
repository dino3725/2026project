# 콜라 실물 비전 예비 측정 — 2026-11-11

**후속 재측정 및 설명 정정:** 새 동기화 RGB-D 10쌍과 영상 시각의 TF로 다시 측정했다. 상자 윗면과 옆 책상 사이의 거리는 평균 76.31mm로, 사용자 실측 80mm에 가깝다. 아래의 +25mm 적용 z는 상자 자체의 높이를 뜻하지 않는다. 책상 면도 함께 올라가므로 절대 좌표 문제와 상자의 상대 높이를 구분해야 한다. 자세한 결과는 [상자 재측정 보고서](box_remeasurement_2026-11-11.md)에 기록했다. 아래는 최초 예비 분석 및 당시 판단을 보존한 것이다.

## 결과와 현재 판단

기존 인식 자세에서 콜라 `/find_object`를 3회 실행해 모두 성공했다. 같은 배치에서 결과의 반복성은 확인했지만, 실제 좌표 정확도와 집기 성공은 검증하지 않았다. 상자 윗면과 카메라 높이 비교는 **구조 변경에 따른 +25mm를 그대로 보정값으로 확정하기에 충분하지 않다**. 실제 URDF·카메라 장착 TF·인식 자세·속도 설정은 변경하지 않았다.

**후속 어깨 실측 반영:** 사용자가 지지면부터 어깨 회전축 중심까지 202mm로 측정했다. 기존 모델 177.5mm보다 24.5mm 높으며, 층간 변경으로 예상한 202.5mm와는 0.5mm 차이다. 이는 팔 장착 높이의 명목상 +25mm 증가를 뒷받침한다. 측정 불확도를 모르므로 0.5mm 차이를 별도 보정하지 않는다. 팔 기준 높이에 대한 근거는 보강됐지만, 이것만으로 카메라 좌표 변환 전체가 검증되거나 상자 윗면의 불일치가 해결된 것은 아니다. 사용자는 카메라 높이 426mm가 정확하지 않을 수 있다고 재차 밝혔으므로 근사 참고값으로 유지한다.

## 실험 조건

- 사용자는 로봇 바퀴와 상자 밑면이 같은 지지면에 있음을 확인했다.
- 상자 높이 80mm, 콜라 지름 약 53mm, 높이 134mm, 세워서 배치했다.
- 콜라 밑면 중심: 바퀴 축 선에서 앞으로 약 290mm, 로봇 중심선에서 좌우 0mm. 근사 실측이다.
- 사용자가 실제 F710 Y 버튼을 눌렀다가 뗐고, 제어 노드의 입력 수신과 정지 처리 진입을 확인했다. 이때 이동 중 물리 정지 시험을 한 것은 아니다.
- 측정용 제어 노드가 기존 인식 목표 `[0, -30, -41, 115]°`로 팔을 한 번 이동했다. 이후 집기·그리퍼·주행 명령 없이 인식 자세를 유지했다.
- 도착 및 최종 확인 관절값은 약 `[0, -29.88, -39.64, 115.14]°`. 시행별 저장값의 joint3는 약 -39.73°였다. 목표와 실제 값은 구분해 보관했으며 자세 튜닝은 하지 않았다.
- RealSense D435i 컬러 영상, 컬러 정렬 깊이, CameraInfo, 관절 상태, TF를 사용했다. 모델은 기존 `best.pt`다.
- 활성 `base_link → link1` 높이는 91mm로 기존 모델 그대로다. 사용자 구조 치수로 계산한 116mm와의 차이 25mm는 기록기의 비교용 z에만 더했다.
- 후속 사용자 실측: 현재 인식 자세에서 지지면부터 카메라 렌즈 중심까지 **약 426mm**. 렌즈 종류와 측정 불확도는 미확인이다. 이 값은 원래 `session.json` 생성 이후 받은 값이므로 원본 세션을 덮어쓰지 않고 실측 YAML과 진단 JSON에 추가했다.

## 알려진 높이와의 대조

### 카메라 높이

원본 모델의 `base_link`는 공통 지지면보다 10mm 높다는 가정을 유지한다.

| 비교 항목 | 지지면 기준 높이 |
|---|---|
| 저장된 TF의 컬러 광학 프레임 | 409.83mm |
| 구조 증가량 +25mm만 적용한 계산 | 434.83mm |
| 사용자의 렌즈 중심 근사 실측 | 약 426mm |

실측은 기존 모델보다 약 16.17mm 높고, +25mm 계산보다 약 8.83mm 낮다. 렌즈 중심의 정의와 실측 불확도도 있어 이 차이를 단독으로 새 카메라 오프셋으로 사용할 수 없다.

### 상자 윗면

저장 영상에서 콜라와 겹치지 않는 윗면 5지점을 수동 선택했다. 픽셀 `(500,550), (650,600), (900,550), (500,400), (900,400)`의 7×7 유효 깊이 중앙값을 세 시행의 깊이 PNG에서 읽고, 내부 파라미터와 세션 시작 시 저장된 TF로 변환했다. 총 15점이다.

- 상자 윗면의 예상 `base_link` 높이: 80 − 10 = **70mm**.
- 원본 모델로 계산한 높이: **64.65~70.94mm**.
- +25mm를 더한 비교용 높이: **89.65~95.94mm**.
- +25mm 적용 후 예상 높이와 차이: **+19.65~25.94mm**.

이 대조에서는 원본 z가 상자 높이에 더 가깝다. 그러나 카메라 실측 높이는 원본 TF보다 높으므로, 이것만으로 기존 모델이 맞거나 층간 변경을 무시해도 된다고 결론 내릴 수 없다. 팔 기준 높이, 카메라 장착 위치·각도, 관절 자세, 실측 기준을 함께 확인해야 한다. 원인은 아직 특정하지 않았다.

이것은 정식 평면 보정이 아닌 오프라인 진단이다. RGB·깊이·debug 스냅샷 시각이 서로 다르고, 사용한 TF는 각 깊이 영상 시각의 TF가 아니다. 정지 배치와 거의 같은 관절값을 이용한 참고 계산이며, 윗면 굴곡·수동 지점 선택·깊이 노이즈·실측 불확도도 남아 있다.

## 다음 단계

1. **완료:** 팔 어깨 관절 중심 높이 202mm를 받아 예상 202.5mm와 대조했다. 명목상 +25mm 구조 증가를 지지한다. 실측 0.5mm 차이로 모델을 미세 조정하지 않는다.
2. 확인된 팔 기준 높이를 바탕으로, 상자 윗면의 알려진 높이와 여러 위치의 관측을 이용해 카메라 장착 위치·각도를 검증한다. 콜라 중심과 표면점의 차이를 보정 오차에 섞지 않는다.
3. 근거가 확보된 모델 변경만 적용한 뒤 같은 배치에서 다시 측정하고, 다른 거리·좌우 위치에서도 확인한다.
4. 좌표 기준과 집기점 정의가 확인된 뒤 접근·집기 시험으로 넘어간다. 이번 3/3은 집기 성공률이 아니다.
