# 2026-11-18 Jetson 작업 마감·재개 기록

브랜치: `jetson/development`. `main`에는 반영하지 않는다.
사용자 요청에 따라 마지막 푸시 이후 코드와 선별한 실험 자료를 함께 보존한다.

## 완료한 작업

- Nav2/Cartographer 환경 확인 및 `eated_navigation` 준비 패키지. 실제 자율주행 미검증,
  Nav2 속도 출력은 바퀴 입력과 분리되어 있다.
- 비전 표면 좌표 선택 개선, 검출 중단 시 표본 초기화, RGB/깊이 촬영 시각·중복·최신성 검사,
  깊이 영상 시각의 TF 사용. 일반 비전 기본값은 `candidate`다.
- RGB-D/TF/관절 기록, 물체 중심축·접촉점·모델 TCP·도구 목표의 분리 계산.
- 읽기 전용 후보 계획과 직선 하강/상승의 FK 검사, 손가락 메시 구간별 경계와 잡힌 캔의
  움직임을 반영한 모델 영역 검사. 일반 control의 기존 파지 계산에는 아직 연결하지 않았다.
- 일회성 접근 시험 제어기, 집게 열기 전용 시험 도구, eateded의 촬영/접근 시험 모드와
  종료 신호 종류 및 프로세스 식별자 기록.

## 실제로 확인한 범위

새 접근점까지 팔을 한 번 이동했고 사용자가 **콜라와 닿지 않고 떨어져 있음**을 확인했다.
센서+URDF 도구 끝점은 목표보다 Z 약 18.94mm 낮았다. 실제 손끝 실측 오차는 아니다.
모델 후보 중 캔 윗면 아래 15mm 후보가 최소 분리 간격 기준으로 선택됐으나
실제 하강·파지·상승은 실행하지 않았다. 집게 열기 요청도 통신 입력 부재로 실행 전 거부됐다.

모델의 절대 정확도, 장착부/케이블, 실제 집기 성공률은 미검증이다.
기존 실패한 접근의 실제 접촉과 모델 불일치도 해결된 것으로 처리하지 않는다.
사용자 결정에 따라 추가 자 측정 없이 명목 모델을 사용하며 미측정값은 실측값으로 기록하지 않는다.

## 종료 상태

01:01:01의 첫 예기치 않은 종료는 종료 신호 수신까지만 알 수 있다. 사용자 직접 종료는 아니었다.
기록을 보완하고 01:06:08 촬영 전용 실행과 HOME 복귀를 완료했다.
그 뒤 **01:34:27 SIGHUP → 01:34:29 종료 완료**가 새 로그에 남았다.
SIGHUP을 보낸 주체는 미확인이다. 전원 문제라고 단정하지 않는다.

마감 시 프로세스 조회에서 eateded, 하드웨어 드라이버, MoveIt, 카메라, 비전,
조이스틱 및 시험 제어기가 남아 있지 않음을 확인했다. 추가 종료 명령이나 로봇 이동은 하지 않았다.
공급 드라이버는 종료 때 자체 복귀/집게 초기화를 수행하므로 물리 팔 자세를 마지막 접근
자세나 HOME으로 확정해서 기록하지 않는다. 다음 실행에서 새 관절 정보를 읽어야 한다.

최종 로그: `log/eateded_20261118_010533_850510/monitor.log`.
선별 사본: `data/2026-11-18/grasp_segments/restart_monitor.log`.

## 다음 재개 순서

1. 기존 카메라 장착과 8cm 상자/콜라 배치를 영상으로 확인한다. 추가 실측은 요구하지 않는다.
2. 하드웨어를 시작하면 자체 초기화/기존 HOME 이동이 있음을 고려한다.
3. 새 RGB-D/TF/관절값으로 좌표와 경로를 다시 만든다. 저장된 `plan.json`은 시험 이력이며
   실행 완료된 접근 계획이나 과거 시작 관절을 재사용하지 않는다.
4. 기존 집게 열림값으로 열고 좌우 정렬을 확인한다. 보이지 않는 접촉 여부만 필요한 경우
   사용자에게 육안 확인을 요청한다.
5. 하강·실제 파지·상승 한 회차를 확인한 뒤 일반 실행 연결 및 반복 성공률 평가를 진행한다.

`eateded --recognition-audit`는 `pick_enabled=false`와 비교용 `localization_mode=legacy`를
명시적으로 선택한다. 일반 실행의 candidate 기본값과 혼동하지 않는다.
속도/가속 0.10, 고정 자세/집게 기본값, Y/음성 stop과 취소 경로를 유지한다.
