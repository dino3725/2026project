## 이번까지 확보한 결과

1차 원본은 `log/handeye_desk_fixed_20261111_01/`, 2차는 `log/handeye_desk_fixed_20261111_02/`다.
각각 학습 13개·검증 3개 관측, 번호별 이동 15회가 완료됐다. 두 세션 합계 관측 32개·이동 30회이며,
세션 사이에 같은 자세가 포함되므로 전체가 서로 다른 32개 자세라는 뜻은 아니다.

| 항목 | 결과 |
|---|---|
| 사용자 손목 중심 높이 | 43.9cm — **1차 마지막 자세**에서 측정 |
| 그 자세의 모델 손목 높이 | 44.087cm, 실측과 약 1.87mm 차이 |
| 손목 실측 해석 | 해당 지점의 높이만 대조. 팔의 전체 xyz·각도·모든 영점 정확도를 입증하지 않음 |
| 출력 무늬 실측 | 가로 177mm·세로 125mm, 설계 175×125mm |
| 인쇄 비율 | 가로 약 +1.14%, 세로 동일. 측정 불확도는 미제공 |
| 기존 카메라 TF | (−0.065, 0.0195, 0.052)m, rpy=(0,0,0) 유지 |
| 카메라 내부 파라미터·깊이 스케일 | 변경하지 않음 |
| 새 장착 후보 | 모두 적용 보류/거절 |

1차 원래 크기 가정의 Park 후보는 검증 최대 2.62mm·0.269°였으나, 책상 높이가 RGB 약 +14.88mm,
깊이 평균 약 +11.76mm로 남았다. 2차는 yaw 범위를 ±18°, 어깨를 +20°까지 넓히고 팔꿈치·손목
조합을 최대 ±8° 바꿨다. 모든 이동·촬영이 완료됐으나 Park 후보의 학습 최대 위치 차이 7.90mm,
검증 최대 5.44mm로 내부 선별 기준 5mm를 넘었다. 최종 카메라 장착값으로 적용하지 않았다.

두 세션 모두 학습 후보를 먼저 저장한 뒤 별도 검증 자세를 촬영했다. 2차는 Park와 코너 재투영
최적화 후보를 모두 검증 촬영 전에 저장했다. 서로 다른 계산 방법과 자세 범위에서 장착값이
크게 달라져, 낮은 단일 영상 재투영 오차만으로 장착 보정이 완료됐다고 해석하지 않는다.

## 출력 크기 실측 후 재계산

`recompute_board_geometry.py`로 원본 픽셀 관측은 보존하고, 물체점의 x/y 축에 각각 177/175, 125/125를
곱해 재계산했다. 각 축 내부의 인쇄 배율이 균일하다는 가정이다. 기존 검증 영상을 재사용한
진단이며 새로운 독립 촬영 검증은 아니다.

| 데이터 / 방법 | 책상 기준 표식 중심 계산 높이 | 검증 최대 위치 차이 |
|---|---:|---:|
| 1차 / Park | +12.85mm | 2.94mm |
| 1차 / 코너 재투영 최적화 | −16.75mm | 2.46mm |
| 2차 / Park | +52.35mm | 5.86mm |
| 2차 / 코너 재투영 최적화 | +10.85mm | 5.91mm |

인쇄 크기 차이는 확인된 문제지만, 이를 반영해도 남은 불일치가 해결되지 않았다.
높이를 강제로 0으로 만드는 제약이나 물체별 z 오프셋을 넣지 않았다.
손목 높이가 모델에 가깝다는 사실만으로 팔 각도·수평 위치 오차나 기구학 문제를 배제하지 않는다.

2차 학습 영상만으로 초점거리 민감도도 점검했다. 비율을 고정하면 fx 약 919px(기존 약 912px),
fx/fy를 따로 풀면 약 822/802px처럼 다른 결과가 나왔다. 표식 법선 방향과 화면 분포가 제한되어
있고 인쇄 크기 가정도 포함된 진단이므로, 이를 유효한 카메라 내부 보정값으로 적용하지 않았다.

## 재개 지점

다음은 **카메라와 로봇은 고정하고 표식판만 움직여서 카메라 내부 파라미터를 별도 검증**하는 단계다.
팔 기구학과 카메라 내부 모델의 영향을 분리하려는 절차이며, 공장 보정이 잘못됐다고 확정한 것은 아니다.

- 사용자는 별도 받침판을 찾기 어렵다고 했다.
- 기존 상자(윗면 350×260mm, 높이 80mm)를 닫아 통째로 들어도 윗면이 단단하고 평평하다고 확인했다.
- 따라서 이 상자를 표식판 받침으로 쓰기로 했다. 종이 긴 변을 상자 350mm 변에 맞추면 A4 전체가 들어간다.
- 종이를 상자에 붙여 달라고 요청한 직후 사용자가 종료를 요청했다.
  **종이를 실제로 상자에 붙였는지는 아직 확인하지 못했다.** 재개 시 이 상태부터 확인한다.
- 새 내부 보정용 수집기를 실행하거나 내부 보정 촬영을 시작하지 않았다.
- 다음 수집에서는 실제 무늬 크기 177×125mm를 명시적으로 사용해야 한다. 기존 `board.json`과
  `BOARD_SPEC`은 설계상 정사각형 25mm 보드를 뜻하므로 실측 인쇄 치수와 혼동하지 않는다.
- 로봇의 별도 테스트로 자세·배치가 달라져도 내부 보정은 새 조건을 기록하고 진행할 수 있다.
  기존 고정 표식판 장착 보정 세션에 새 배치를 섞지 않는다.
- 내부 보정은 충분한 화면 위치·거리·서로 다른 기울기의 학습 관측과 별도 검증 관측이 필요하다.
  출력물 평탄도와 크기를 확인하고, 카메라 설정에 적용하기 전에 검증한다.
