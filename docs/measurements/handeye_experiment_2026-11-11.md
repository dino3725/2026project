# 카메라 장착 보정 1차 실험 — 2026-11-11

이 문서는 1차 실험 당시 기록이다. 이후 손목 실측 43.9cm, 2차 촬영, 출력 무늬 실측 177×125mm와
재계산을 진행했다. 사용자 요청으로 프로세스를 모두 종료했으며,
[최신 재개 메모](RESUME_AFTER_PAUSE_2026-11-11.md)에 후속 결과와 다음 단계를 기록했다.

## 결과

실제 로봇으로 학습용 13개 자세, 별도 검증용 3개 자세를 촬영했다.
총 15회 번호별 이동이 완료됐고, 각 이동 후 정지와 준비 상태를 확인한 다음 RGB·깊이·TF를 저장했다.
팔은 마지막 15번 자세를 유지한다. 자동 HOME, Pick, 그리퍼 동작, 베이스 주행은 수행하지 않았다.

**보정 후보는 상대 일관성 검사를 통과했지만, 책상 기준 절대 높이 차이가 남아 적용을 보류했다.**
이미 반영한 것은 팔 장착 높이 모델의 +25mm이며, 카메라 장착 TF는 기존 값을 유지한다.

## 실행 조건과 데이터

- 표식판: 7×5칸 ChArUco, 한 칸 25mm, 책상에 직접 테이프로 고정.
- 사용자가 인쇄 경계·무늬·100mm 기준선, 표식 고정, 주변 정리, 물리 Y 누름/뗌을 확인했다.
- 로그에서도 새 보정 제어기의 `Physical Y input verified`를 확인한 뒤 실행했다.
- 모델: `base_link→link1` z=116mm, 어깨 중심 접지면 높이 202.5mm.
- 하드웨어 드라이버는 계속 유지했다. 관절별 목표는 기존 `_send_goal` 등록·취소 경로를 사용했다.
- 각 자세는 번호별 서비스 하나로 요청했으며, 완료 확인 전에 다음 목표를 발행하지 않았다.
- 움직임은 joint1 ±12°, joint2 +0~12° 범위이고 joint3·joint4는 계획 기준으로 고정했다.
- 이동 시간 4초, 기존 MoveIt 속도·가속 배율 및 작업용 자세 값은 변경하지 않았다.
- 첫 자세 `train_00`을 포함해 학습 13개. 검증 3개는 촬영 전부터 역할을 지정했다.
- 학습 결과와 입력 해시를 `training_frozen.json`에 저장한 **뒤** 검증용 자세를 촬영했다.
  최종 계산의 학습 변환이 동결된 결과와 일치함을 확인했다.

## 상대 일관성 검증

16개 영상 모두 ChArUco 코너 24개를 검출했다. 모든 저장 쌍의 RGB–depth 시각 차이는 0ms였다.
각 RGB 촬영 시각에 팔 끝 TF를 조회했고, 동일 stamp의 RGB CameraInfo를 사용했다.

같은 고정 표식판을 여러 자세에서 보았을 때, 로봇 좌표계에서 계산되는 표식판 자세가 얼마나
일치하는지 비교했다. 각 모델의 학습 관측으로 구한 표식판 기준 자세에 대해 검증 관측을 평가했다.

| 지표 | 기존 카메라 장착값 | Park 보정 후보 |
|---|---:|---:|
| 검증 3개 자세의 최대 위치 차이 | 3.01mm | 2.62mm |
| 검증 3개 자세의 최대 각도 차이 | 0.493° | 0.269° |
| 학습 13개 자세 최대 위치 차이 | candidate_review.json 참조 | 4.93mm |
| 학습 13개 자세 최대 각도 차이 | candidate_review.json 참조 | 0.413° |

사전에 둔 내부 선별 기준(최대 5mm·1°)은 통과했다.
이는 **절대 위치 정확도 2.62mm를 달성했다는 뜻이 아니다**. 같은 오프셋을 공유하면 일관성이
좋아도 물리적인 책상 높이는 틀릴 수 있다. 따라서 별도 절대 기준 점검을 함께 수행했다.

## 보정 후보와 민감도

`end_effector_link→d435i_link` 후보는 다음과 같다. 아직 발행하거나 기본값으로 저장하지 않았다.

| 항목 | 기존 | 후보 |
|---|---:|---:|
| x | −65.00mm | −46.59mm |
| y | 19.50mm | 20.77mm |
| z | 52.00mm | 53.82mm |
| roll | 0° | −1.470° |
| pitch | 0° | 1.848° |
| yaw | 0° | −0.148° |

광학 프레임에서 계산한 결과를 `T_ee_camera = T_ee_optical × inverse(T_camera_optical)`로 변환했다.
카메라 내부 파라미터·공장 보정·깊이 스케일은 변경하지 않았다.

학습 자세 하나씩을 제외한 민감도 점검에서 x 범위 −48.57~−45.41mm,
y 20.08~21.76mm, z 52.23~55.31mm였다. 기준 후보와의 회전 차이는 최대 약 0.555°였다.
이는 상관된 관측의 민감도 점검이지 통계적인 신뢰구간이 아니다.

학습 데이터만으로 다른 OpenCV 방법도 진단했다. Park와 Horaud는 거의 일치했고,
Tsai는 y가 약 2.9mm 달랐다. Daniilidis는 학습 최대 위치 차이 5.36mm,
Andreff는 34.50mm로 나빴다. 방법 간 차이는 충분히 주의할 지표이며, 검증 데이터를 보고
방법을 골라 바꾸지 않았다. 첫 Park 후보와 검증 결과를 그대로 보존했다.

## 절대 책상 높이와 깊이 영상 대조

로봇 바퀴와 표식 종이가 같은 책상에 놓였으므로, 종이 높이는 접지 평면에서 거의 0이어야 한다.
종이·테이프 두께는 독립 측정하지 않았지만 12~15mm 높이 차이를 바로 설명하는 것으로 취급하지 않는다.
`base_link`의 접지면 대비 높이 10mm를 포함해 비교했다.

| 계산 방식 | 기존 장착값 | 후보 |
|---|---:|---:|
| RGB 표식 자세의 학습 기준 중심 높이 | +37.12mm | +14.88mm |
| 깊이 평면으로 계산한 중심 높이 평균(16개) | +34.06mm | +11.76mm |
| 깊이 평면 중심 높이 범위 | +30.81~+38.29mm | +8.27~+14.95mm |

깊이 검사는 검출된 안쪽 코너의 볼록껍질 안에서 가장자리를 9px 줄인 영역을 사용했다.
0.2~1.2m 유효 깊이 점을 추출해 반복적으로 이상점을 제외한 평면을 맞췄으며,
RGB 표식 중심의 광선이 그 평면과 만나는 점을 비교했다.

RGB 표식 평면과 깊이 평면의 중심 법선 방향 차이는 평균 3.24mm(0.58~7.79mm),
법선 각도 차이는 평균 0.99°(0.44~1.76°)였다. RGB 표식 거리와 깊이가 완전히 같지는 않지만,
카메라 후보를 사용해도 두 방식 모두 책상을 접지면보다 높게 계산했다.

따라서 지금 단계에서 모든 원인을 카메라 내부 보정이나 깊이 스케일로 단정하지 않는다.
남은 값을 물체 보정값이나 z 오프셋으로 무조건 빼지도 않는다.
팔 기구학·관절 영점·장착 위치·관측 각도 범위의 영향이 남을 수 있다.
이번 촬영에서 joint3·joint4를 고정했으므로, 다른 팔 형태에 대한 일반화도 아직 검증되지 않았다.

## 다음 확인

현재 15번 자세에서 **책상 표면부터 손목 관절 회전축 중심까지의 수직 높이**를 사용자에게 요청했다.
카메라를 거치지 않는 물리 측정으로 팔 모델의 높이도 맞는지 확인하기 위한 것이다.
마지막 관측의 모델 예측 손목 중심 높이는 약 44.09cm지만, 측정 유도를 피하도록 질문에는 이 값을 넣지 않았다.
측정 중 추가 팔 이동은 하지 않는다.

측정과 모델이 다르면 팔 기구학·영점·구조부터 대조한다. 대체로 맞으면 더 넓고 다양한 자세에서
카메라 장착 추정을 확인하고, 필요한 경우 내부 파라미터를 별도 검증한다.
측정 오차와 종이 지지 상태도 함께 고려하며 단일 실측값만으로 원인을 확정하지 않는다.
