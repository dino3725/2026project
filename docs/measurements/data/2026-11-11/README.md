# 2026-11-11 측정 수치 및 재현 기록

원본 `log/vision_baseline_20261111/`에서 JSON·CSV·분석 Python 코드 13개를 복사했다. CSV는 Git 보관본의 줄바꿈만 LF로 정규화했으며 값은 그대로다. GitHub에서도 보고서의 근거 수치를 확인할 수 있도록 보존한다. 각 파일과 로컬 원본 이미지의 원본 크기·SHA256과 Git 보관본 SHA256은 [manifest.json](manifest.json)에 있다.

RGB·debug 이미지에는 주변 사람이 포함되어 있어 로컬에 보존한다. 깊이 이미지를 포함한 전체 원본 64개는 다음 경로에 해시 검증한 압축 백업으로 저장했다.

```text
/home/fcsl/2026project/log/backups/measurements_2026-11-11.tar.gz
```

압축파일에는 `vision_baseline_20261111/` 디렉터리가 들어 있다. 기존 파일을 덮어쓰지 않도록 별도의 빈 디렉터리에 풀어 사용한다. 분석 스크립트는 해당 측정 디렉터리의 깊이 PNG와 JSON을 읽으므로, GitHub의 수치 파일만으로는 재계산할 수 없다. 전체 백업을 풀면 원래 구조에서 실행할 수 있다.

이 기록은 당시의 원본을 보존한다. 후속 사용자 실측과 표면 평면성에 대한 주의사항은 [최종 작업 기록](../../SESSION_2026-11-11.md) 및 최신 실측 YAML을 함께 참고한다. 관측된 평면 기울기는 확정 카메라 보정값이 아니다.
