# 콜라 자세별 관절 오차 반복 시험 — 2026-11-17

## 시험 방법

사용자가 도착 오차 때문에 다음 자세를 막지 않는 반복 시험을 요청했다.
시험 전용 `ObjectPoseTrials`에서 각도·위치 도착 오차를 관측값으로만 기록하며,
일반 `control_node`의 도착 기준은 유지했다. Y/음성 stop, 입력 유실,
이동 액션 실패, 잘못된 경로/상태 데이터는 계속 중단 조건이다.
주행과 손바닥 자동 놓기는 차단하고, 명시적인 서비스로 각 회차 시작·물체 놓기를 요청한다.
사용자는 각 회차에서 물체를 받은 뒤 상자 위에 다시 놓는다.

기존 HOME/인식/CARGO 자세, 4초 관절 이동, MoveIt 속도·가속 배율 0.10,
그리퍼 값과 힘, 카메라 장착값, 물체 보정값은 변경하지 않았다.

오차는 **관절 센서각 − 명령한 목표 관절각**이다. 이동 액션 완료 후 0.5초를
기다리고 다음 1초 동안 신선한 관절값을 수집한다. 회차별 평균을 먼저 계산하고,
회차별 평균에 같은 가중치를 주어 최종 평균을 계산한다. 자료에는 절댓값 평균,
최대 절댓값, 회차 평균의 표본 표준편차도 남긴다.
시작 HOME과 물체를 놓은 뒤 HOME 복귀는 이동 이력이 달라 따로 집계한다.

PREGRASP/PICK/RETREAT의 목표 관절각은 매회 MoveIt 계획에 따라 달라질 수 있다.
각 회차의 해당 계획 끝점과 비교한 오차이며, 모든 회차가 완전히 같은 관절 자세나
물체 위치에서 수행됐다고 가정하지 않는다. 손끝 위치의 독립 실측 결과도 아니다.

YOLO 인식이 성립하지 않았다. 사용자가 콜라로 바꾸도록 요청하여 물체를 변경했다.

수동 RGB-D 목표 검토는 읽기 전용으로만 수행했으며 최종 콜라 시험은 기존 YOLO를 사용한다.

콜라 예비 접근에서는 MoveGroup 결과를 읽는 기존 도착 검사 오류를 발견했다.

목표 오차 검사는 명령 기준인 `planned_trajectory` 끝점을 사용하도록 수정했다.
일반 제어기에도 같은 수정이 적용되며, 빈 계획이나 잘못된 관절 목록은 계속 거부한다.

최종 반복 측정은 이 수정 후 `log/coke_pose_trials_20261117_02/`에서 새로 시작한다.
