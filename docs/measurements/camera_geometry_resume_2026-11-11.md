# 중단 후 재개: 카메라–책상 좌표 검증

**종료 시 추가 확인:** 사용자가 표면이 완벽히 평평하지 않을 수 있다고 설명했다. 책상/상자 중 어느 표면인지 특정되지 않았다. 따라서 아래 평면 근사·평행성 가정은 미검증이며, 약 2.9°를 카메라 장착 오차로 단정하거나 보정값으로 적용하지 않는다. 다음에는 기준면의 평면성 및 로봇 지지면과의 관계를 먼저 확인한다. 오늘의 최종 상태와 백업 위치는 [작업 종료 기록](SESSION_2026-11-11.md)에 있다.

## 진행한 작업

사용자가 로봇·상자·콜라 배치 유지와 주변 정리를 확인했다. 별도 테스트 후 기존 ROS 프로세스가 종료 상태임을 확인했고, 최초 측정에 기록한 모델 가중치·control/vision 설정·카메라 launch·측정 제어 소스의 SHA256이 그대로임을 확인했다.

측정 제어·F710·D435i를 다시 시작하고 새 프로세스에서 실제 Y 누름/해제를 확인했다. 하드웨어 컨트롤러 활성화 후 기존 인식 자세로 이동해 준비 완료를 확인했다. 카메라 장착 TF는 기존 값 `end_effector_link → d435i_link = [-65,19.5,52]mm, rpy=0`를 별도 static publisher로 발행했다. 이번에는 깊이 기반 좌표 검증을 하므로 YOLO와 손 인식 노드는 재시작하지 않았다.

팔 인식 자세 외 집기·그리퍼·주행 동작은 실행하지 않았다. URDF와 장착 TF 값도 변경하지 않았다.

## 새 데이터와 영역 검증

`geometry_resume_01`에 새 RGB-D 10쌍을 저장했다. 각 쌍의 타임스탬프 차이는 모두 0ms이며, 깊이 영상 시각의 TF를 사용했다. 새 영상에 책상 위 바세린·자·휴지 등이 보여, 이전 ROI를 그대로 사용하지 않고 물체를 피한 영역을 선택했다.

책상 학습 영역(이미지 xyxy, 끝 좌표 제외):

- 앞 왼쪽 `[80,550,260,680]`
- 중간 왼쪽 `[245,350,320,500]`
- 앞 오른쪽 `[1130,610,1230,680]`

상자 윗면 적합 영역은 `[450,360,600,580]`, `[820,350,940,560]`이다. 오른쪽 책상 영역을 처음 더 넓게 잡았을 때 상자 경계 등의 다른 높이 깊이가 섞여 평면 잔차가 약 11mm로 커졌다. 현재 영상과 깊이 분포를 확인해 명확한 책상 내부로 영역을 줄였으며, 최종 책상 평면 적합 잔차 RMS는 평균 1.34mm(1.07~1.69mm)다. 사용자의 80mm 값에 맞추기 위한 좌표 보정은 하지 않았다.

평면을 적합하는 데 쓰지 않은 별도 영역도 검증했다.

| 검증 영역 | xyxy | 책상 평면 기준 높이: 프레임별 중앙값의 평균 |
|---|---|---:|
| 책상 왼쪽 | `[140,500,260,540]` | +0.17mm |
| 책상 오른쪽 | `[1140,550,1220,595]` | -0.09mm |
| 상자 앞쪽 윗면 | `[460,585,900,615]` | 78.76mm |

독립 책상 영역의 프레임별 중앙값 범위는 왼쪽 -0.42~1.14mm, 오른쪽 -0.51~0.39mm다. 상자 앞쪽은 78.22~79.40mm로 사용자 높이 80mm와 가깝다. 이 작은 산포는 절대 측정 오차의 상한이 아니다.

## 무엇이 더 확인됐는가

| 항목 | 이번 관측 |
|---|---:|
| 책상·상자 공통 법선 평면 간 거리 | 평균 77.62mm, 범위 77.36~77.96mm |
| 별도 상자 앞쪽의 책상 기준 높이 | 평균 78.76mm |
| 현재 base_link 수직축에 대한 책상 평면 법선의 기울기 | 평균 2.86°, 범위 2.47~3.08° |
| 카메라 광학 원점에서 책상 평면까지 수직 거리 | 평균 420.30mm, 범위 418.88~421.32mm |
| 기존 모델 카메라 높이에 팔 증가량 +25mm를 더한 값 | 평균 434.94mm |

카메라–책상 수직 거리는 깊이 점들로 적합한 평면과 카메라 원점 사이의 거리이므로, 선택한 로봇 좌표계의 평행 이동·회전에 불변이다. 다만 깊이 편향과 평면 근사의 영향을 받는다. 사용자의 카메라 높이 약 426mm는 불확도가 없는 근사 참고값으로 계속 보관하며 새 깊이 측정으로 덮어쓰지 않는다.

기존 모델 기준 책상 z 중앙값은 약 3.41mm, 상자 윗면은 약 80.02mm다. +25mm를 비교용으로 적용하면 각각 약 28.41mm와 105.02mm가 된다. 이러한 윗면 절대 z는 상자 자체의 높이가 아니다.

책상을 지지면으로 삼았을 때 모델상 기울기와 카메라 높이 차이가 함께 관찰된다. 따라서 일정한 z 오프셋 하나만 정하는 방식으로 원인을 확정할 수 없다. **카메라가 실제로 정확히 2.86° 틀어졌다는 판정은 아니다.** 팔 기구학/관절 기준, 카메라 장착 변환, 실제 지지 조건과 센서 오차를 이 정지 자세 하나로 분리하지 못했다.

## 다음 단계와 한계

현재 데이터로 책상 기준 상대 높이를 안정적으로 추정할 근거는 얻었다. 그러나 하나의 평면만으로는 평면 내 이동 두 성분과 법선 주위 회전을 결정할 수 없고, 현재 팔 자세 하나만으로 팔 기구학과 카메라 장착 오차를 분리할 수도 없다. 실제 로봇 설정에 임의의 보정 TF를 적용하지 않았다.

다음에는 현재 팔·카메라를 옆에서 본 장착 상태를 기존 모델의 장착 기준과 대조한다. 사진은 큰 장착 방향·기준점 차이를 확인하는 자료이며 정밀 6자유도 보정을 대신하지 않는다. 필요 시 알려진 3차원 기준점 또는 추가 자세 관측을 사용해 검증한 뒤 보정을 적용한다.
