## 알아 둘 점

- 새 `.venv`에는 numpy 2.x가 깔렸습니다. ROS Humble과 충돌하는 오류가 나면 `.venv/bin/pip install 'numpy<2'`.
- Jetson 코드는 노트북에서 수정·push하고 Jetson에서 pull·빌드·실물 확인하는 흐름을 기본으로 합니다.
- 실물 시험(로봇을 움직이는 명령)은 항상 사용자가 직접 합니다. `.claude/settings.json`에서 해당 명령을 막아 두었습니다.
- 매니퓰레이터 실험 중에는 속도 0.10 유지, 조이스틱 Y 버튼 대기, 책상 위 실험 물체만 두기.
